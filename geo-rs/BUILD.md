# geo-rs build & test

geo-rs is the Meridian spatial engine (Rust, axum). It is **review-only** in the
current hardening pass: no Rust toolchain was available in the build
environment, so the crate was not compiled or tested here.

## Prerequisites

Install the Rust toolchain via rustup:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

## Build

```sh
cd geo-rs
cargo build --release
```

The binary is produced at `target/release/geo-rs`. `Cargo.lock` should be kept
under version control once generated by the first successful build.

## Test

```sh
cargo test
```

## Run

```sh
./target/release/geo-rs
```

Environment: see the root README "Production profile" section for shared
service configuration. The service serves point-in-polygon lookups against
`data/` GeoJSON boundaries with a haversine prefilter.
